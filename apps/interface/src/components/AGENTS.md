# AGENTS.md — interface · `src/components/`

Everything a page composes: the editor's canvas, palette, inspector and test console; shared
widgets; the AI Gateway and Settings tabs; the run waterfall; and the shadcn/ui primitives.
Rules in [apps/interface/AGENTS.md](../../AGENTS.md) apply first.

### The editor (used by `routes/Editor.tsx`)

| File | What it does |
|------|--------------|
| [`GraphCanvas.tsx`](GraphCanvas.tsx) | The React Flow canvas. Seeded from the IR, re-seeded only on structural change; positions commit to `view` on drag stop. One of the two components allowed to know React Flow |
| [`NodeView.tsx`](NodeView.tsx) | The custom node: one handle per declared port, keyed by port id, coloured by role |
| [`Palette.tsx`](Palette.tsx) | Node palette derived from the generated `NODE_TYPES`, grouped by kind; drag or click to add |
| [`Inspector.tsx`](Inspector.tsx) | The right panel: per-node Wizard (schema-driven forms) ⇄ per-node Code, ports, `$in` inputs, LLM messages/tools/params, the Tool node panel, guardrail, edge, trigger and graph panels. Keys that need a custom form get a case in its dispatch |
| [`NodeCodeEditor.tsx`](NodeCodeEditor.tsx), [`IRCodeEditor.tsx`](IRCodeEditor.tsx) | CodeMirror JSON editors for one node and for the whole document |
| [`ModelParamsPanel.tsx`](ModelParamsPanel.tsx) | Literal generation params on a model binding or an audio node, via the bench's schema-driven forms |
| [`AddMcpToolsDialog.tsx`](AddMcpToolsDialog.tsx) | Bulk-add `mcp_tool` nodes from a server's tool list, wired into an llm's tools port |
| [`CrawlersDialog.tsx`](CrawlersDialog.tsx), [`CrawlerNodePanel.tsx`](CrawlerNodePanel.tsx) | The Crawlers browser (through `/crawlers/catalog*`) and the `crawler` node's inspector |
| [`TestPanel.tsx`](TestPanel.tsx) | Runs the current canvas document through `POST /graphs/runs`, lights nodes from the trace stream |
| [`ResumePanel.tsx`](ResumePanel.tsx) | Delivers input to a run waiting at a human node (`POST /runs/{id}/resume`) |
| [`IconPickerGrid.tsx`](IconPickerGrid.tsx) | Lazy icon search over the full Lucide set (stored in `view`, never hashed) |

## Rules specific to this folder

- Only `GraphCanvas.tsx` and `NodeView.tsx` (with `src/adapter/`) may know React Flow's shapes.
- New UI composes `ui/` primitives and `ui.tsx` wrappers, styled with semantic tokens.
- Secrets are write-only everywhere: render `hasSecret` / `hasValue` / `{set, names}`, never a
  value.
