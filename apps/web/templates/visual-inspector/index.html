Visual inspector: Vision in a Pipeline

Vision inside a pipeline, not a chat window: a local vision model inspects an image against your acceptance criteria, emits a structured pass/fail verdict, and a router sends the run down the matching branch — the skeleton of a visual QC line. The image URL is fetched by the inference plane itself, so it must be one that host can reach (a data: URI works too).

How It Works

A local vision model checks an image against your acceptance criteria and emits a minified JSON verdict — pass or fail, with a reason. A JSON-schema guardrail catches a malformed verdict and routes it to Rejected, and a router sends well-formed verdicts down the matching branch.

The skeleton of a visual quality-control line: vision as a pipeline step with structured output, not a chat window.

Try It

  1. In TheYgent, open Settings → Samples.
  2. Fill the model slots below with models from your registry, then click Install on Visual inspector.
  3. Open the installed agent and run it with the example input.
