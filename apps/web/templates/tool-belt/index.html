Tool belt: Step Tools vs. LLM-Driven Tools

The two ways to use a tool, in one agent: a GraphQL API turned into an MCP server runs as a flow STEP (it always executes), while a REST API turned into an MCP server is WIRED TO the local model as a capability the model decides to call. A rate-limit gate protects the whole flow.

How It Works

Two ways to use a tool, side by side, behind a rate limit. A GraphQL API turned into an MCP server runs as a fixed step — it always executes, with arguments bound from the input. A REST API turned into an MCP server from its OpenAPI spec is wired to the model's tools port instead, so the model decides whether to call it.

Ask about the weather and the model calls the weather tool; ask about the currency and it doesn't. Pick a local model with tool calling.

Try It

  1. In TheYgent, open Settings → Samples.
  2. Fill the model slots below with models from your registry, then click Install on Tool belt.
  3. Open the installed agent and run it with the example input.
