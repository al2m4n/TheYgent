TheYgent Is Now Ertir

TheYgent, the no-code, local-first AI agent platform, has a new name: Ertir. Same code, same maintainer, same license. Here is what changed, what didn’t, and where everything moved.

By Arman Bahlakeh

TheYgent is now called Ertir. It is the same project: the same code, the same maintainer and the same license. Version 2.0.0 is the first release under the new name. If a link to theygent.ai brought you here, you’re in the right place.

What Ertir is

Ertir is a no-code, local-first platform for building and running AI agents on a visual canvas. Inference runs on your own machine, with llama.cpp, MLX or vLLM, or on any OpenAI-compatible API you register, chosen per agent and per call. It is source-available fair-code software under the Sustainable Use License, self-hosted on bare metal, Docker Compose or Kubernetes. The promise hasn’t changed: you own every hop.

What changed

  • The name. The app, the docs and this website say Ertir.
  • The website moved from theygent.ai to ertir.dev.
  • The docs moved from docs.theygent.ai to docs.ertir.dev, every earlier version included.
  • The repository is github.com/al2m4n/ertir. GitHub redirects the old al2m4n/TheYgent URLs, so clones, issues and pull requests keep working.

During the move, links to theygent.ai and docs.theygent.ai redirect to the matching page on the new addresses.

What stays the same

Your installation and your data carry over unchanged: agents and their versions, runs, conversations, models, credentials and settings. There is nothing to migrate, and every agent keeps its content hash.

Technical names keep the old spelling, so the scripts and configuration you already have keep working:

  • environment variables: THEYGENT_*
  • the data folder: ~/.theygent
  • headers: X-TheYgent-Signature on webhooks and X-TheYgent-Gateway-Key on the AI gateway
  • Python packages and modules, npm packages, and Docker and Kubernetes names: theygent…

The names people read did change. API titles, the MCP sign-in screen and the AI gateway’s messages and reports now say Ertir, so a script that matched the old “TheYgent AI gateway:” message prefix needs updating. The name change page in the docs lists what changed and what didn’t.

Writing the name

Ertir: a capital E and the rest lowercase, like any other name. Anything technical that carries the new name is all lowercase: ertir.dev, docs.ertir.dev and github.com/al2m4n/ertir. A few places say “Ertir (formerly TheYgent)”, so people and search engines that know the old name find the new one.

Upgrading

Update the way you usually do. Version 2.0.0 has no database migrations and no changes to API routes or to request and response fields. The major version marks the rename of the names people read, listed above.

Where to find everything

  • Website: ertir.dev
  • Docs: docs.ertir.dev
  • Code: github.com/al2m4n/ertir
  • Release notes: v2.0.0

Thank you to everyone who used, starred and reported issues on TheYgent. Ertir is the same project under a new name.

Questions

Asked and Answered.

Is Ertir the same project as TheYgent?

Yes. Ertir is the new name of TheYgent: the same code, the same maintainer and the same license. Version 2.0.0 is the first release under the new name.

Where did theygent.ai and the TheYgent GitHub repository go?

The website moved to ertir.dev and the docs to docs.ertir.dev. The repository is github.com/al2m4n/ertir, and GitHub redirects the old al2m4n/TheYgent URLs.

Do I need to migrate data or change my configuration?

No. Agents, runs, conversations, models, credentials and settings carry over unchanged. Technical names keep the old spelling, so THEYGENT_* environment variables, the ~/.theygent data folder and the X-TheYgent-Signature and X-TheYgent-Gateway-Key headers keep working.

How is the new name written?

Ertir, with a capital E and the rest lowercase. The domains and the repository are all lowercase: ertir.dev, docs.ertir.dev and github.com/al2m4n/ertir.
